# RestReminder 使用说明（中文）

> 一句话：**工作满一小时，它把每块屏幕都盖住，用 5 分钟倒计时叮嘱你起来歇一会儿**；你可以一键结束，也可以最小化到角落继续倒计时。
>
> 适用于 macOS 14 及以上，Apple 芯片和 Intel 芯片都能跑。完全本地运行，不联网、不收集数据、不申请任何系统权限。

## 一、安装

### 方式 A：下载现成 App（推荐给普通使用者）

1. 打开项目的 [Releases 页面](https://github.com/huacracker/RestReminder/releases)，下载最新的
   `RestReminder-x.y.z-macos-universal.dmg`（或 `.zip`）。
2. 双击 dmg，会出现一个窗口，里面是 `RestReminder.app`、一个 `Applications` 快捷方式、一份「Read me first.txt」。
3. 把 `RestReminder.app` **拖进 `Applications`**（也就是拖到窗口右侧那个快捷方式上）。
4. 到「启动台 / 应用程序」里打开它。

> **首次打开被系统拦下是正常现象。** 这个 App 使用的是免费的临时签名（ad-hoc）、**没有做 Apple 付费开发者公证**，所以 macOS 会提示「无法验证开发者」甚至「已损坏，应移到废纸篓」。
> 这不是中毒，也不是文件坏了。任选一种方式放行（只需做一次）：
>
> - **方法一（推荐）**：在「应用程序」里 **右键点** `RestReminder.app` → 选「**打开**」→ 弹窗里再点一次「**打开**」。
> - **方法二**：打开「终端」，粘贴执行下面这行，然后正常双击打开：
>
>   ```bash
>   xattr -dr com.apple.quarantine /Applications/RestReminder.app
>   ```
>
> 如果提示需要输入密码，是你的开机密码（这行命令只是去掉系统给下载文件打的「隔离」标记）。

### 方式 B：从源码构建（推荐给开发者）

只需要 Xcode 命令行工具，**不需要完整 Xcode**（如果没装过，先执行 `xcode-select --install`）：

```bash
git clone https://github.com/huacracker/RestReminder.git
cd RestReminder
./build.sh          # 编译 → 生成图标 → 签名 → 安装到 ~/Applications
./build.sh run      # 顺便启动
```

想自己打一个通用二进制 + dmg + zip（和发布版一样）：

```bash
./build.sh release  # 产物在 dist/
```

## 二、第一次启动：你会看到什么

1. **Dock 里没有图标**，这是正常的 —— 它是菜单栏应用。
2. 看屏幕顶部**菜单栏**，会多出一个 **☕️ 图标**，旁边是「距离下次休息的剩余时间」，比如 `1h00m`。
3. 第一次启动时系统会弹一次通知授权，点「**允许**」即可（不点也不影响提醒，只是少了通知横幅，提示音照常）。
4. 什么都没动的状态下，它不会立刻打扰你 —— 计时从现在开始：**60 分钟后**第一次休息。

想立刻看效果：点菜单栏 ☕️ → 「**现在就去休息**」。

## 三、休息界面说明

时间到了以后，**每一块屏幕**都会出现遮盖界面（双屏/外接显示器会各出现一个）：

**主屏（主要操作屏）**

```
                 该休息了 ☕️              ← 标题
             ╭──────────────╮
             │      4:32    │             ← 圆环 + 倒计时（圆环是剩余进度，随时间消退）
             ╰──────────────╯
     站起来走动一下 · 看看远处 · 喝口水      ← 建议
        [ 我休息好了 ]   [ 最小化 ]        ← 两个按钮
   ESC 结束休息　·　空格 最小化　·　倒计时结束自动关闭
```

**副屏**：只显示一行「休息中 ☕️　4:32」，不干扰你手上的主屏操作。

**最小化之后的悬浮条**（点「最小化」或按空格会出现）：

- 位置：主屏**右下角**（会避开 Dock）。
- 样子：深色圆角小条，写着「☕️ 休息 4:32」。
- 行为：**可以拖动**；倒计时继续走；**点一下**就还原成全屏遮盖。
- 它是「非激活窗口」：显示和刷新的时候**不会抢走你正在打字的键盘焦点**，你可以继续干活。

小细节：

- 休息期间系统**不会让显示器休眠**（防止你没看到提醒就黑屏了），休息一结束就恢复正常省电行为。
- 倒计时归零后遮盖自动消失，并**自动开始下一个 60 分钟工作计时**；自动结束时只发通知，手动结束时还会响一声提示音。

## 四、快捷键

| 操作 | 怎么按 |
|---|---|
| 提前结束休息 | `ESC` 或 `回车`（也可以点「我休息好了」按钮） |
| 把遮盖最小化到角落 | `空格`（也可以点「最小化」按钮） |
| 重新展开遮盖 | 点右下角的悬浮条 |
| 退出整个程序 | 菜单 → 「退出休息提醒」，或 `⌘Q`（退出后计时清零） |

## 五、菜单逐项说明

点菜单栏的 **☕️** 打开菜单：

| 菜单项 | 作用 |
|---|---|
| 顶部状态行（灰色） | 显示当前状态：「距离下次休息 42m」/「休息中 4:32」/「已暂停计时」 |
| **现在就去休息** / **结束这次休息** | 一键进入休息；休息中则变为一键结束这次休息 |
| **暂停计时** / **继续计时** | 暂停后菜单栏显示 `⏸`，计时冻结；点「继续计时」从暂停处接着走。适合你临时要专心一段时间时 |
| **重新开始这一轮** | 把当前这一轮重置，重新开始完整的工作计时 |
| **工作间隔 ▸** | 选工作多久：15 / 25 / 30 / 45 / 50 / 60 / 90 / 120 分钟（当前值前面有对勾） |
| **休息时长 ▸** | 选休息多久：3 / 5 / 10 / 15 分钟 |
| **遮盖所有屏幕** | 勾选（默认）：每块屏都盖；取消：只盖当前主屏 |
| **提示音** | 休息开始/结束时播放系统音（默认开） |
| **语音叮嘱** | 用 macOS 语音念一句「该休息了，站起来走动走动，看看远处」（默认**关**，开了会听到中文朗读，需要系统装有中文语音） |
| **开机自动启动** | 勾选后写入 `~/Library/LaunchAgents/com.restreminder.app.plist`，开机自动运行（默认关） |
| **退出休息提醒** | 完全退出程序 |

> 菜单里显示的对勾/未勾选状态就是当前设置，改完立即生效并自动保存，不用点「确定」。

## 六、设置项速查表

| 设置 | 默认值 | 可选项 | 存在哪 |
|---|---|---|---|
| 工作时长 | 60 分钟 | 15/25/30/45/50/60/90/120 | `~/Library/Preferences/com.restreminder.app.plist` |
| 休息时长 | 5 分钟 | 3/5/10/15 | 同上 |
| 遮盖所有屏幕 | 开 | 开 / 关 | 同上 |
| 提示音 | 开 | 开 / 关 | 同上 |
| 语音叮嘱 | 关 | 开 / 关 | 同上 |

```bash
defaults delete com.restreminder.app
```

## 七、命令行参数（进阶）

这些参数**只在当次运行生效，不会写入配置**（用的是 macOS 的 `NSArgumentDomain`），适合测试和排查。假设 App 装在 `~/Applications`：

```bash
BIN=~/Applications/RestReminder.app/Contents/MacOS/RestReminder

# 自检：立刻走一遍「弹出遮盖 → 最小化 → 还原 → 结束」，打印诊断后退出（返回码 0）
"$BIN" -selftest 1

# 快速跑一轮真实循环：工作 6 秒、休息 12 秒（分钟数支持小数）
"$BIN" -workMinutes 0.1 -breakMinutes 0.2

# 把遮盖界面渲染成图片（不需要屏幕录制权限），用于写文档/截图
"$BIN" -snapshot /tmp/cover.png
"$BIN" -snapshot /tmp/mini.png -snapshotMini 1
```

自检正常时最后一行会打印 `SELFTEST OK`，其中 `screens=2 covers=2` 表示两块屏各盖了一层。

> 同一时间只会运行一个实例（启动第二个会自动让位），所以不用担心重复提醒。

## 八、常见问题 FAQ

**Q1：打开时提示「无法验证开发者」/「已损坏，应移到废纸篓」，是不是文件有问题？**
不是。因为 app 是临时签名、未做 Apple 公证（那是付费开发者账号才有的服务）。按[安装章节](#一安装)里的「方法一」或「方法二」放行一次即可，之后不再提示。

**Q2：装了但菜单栏找不到图标？**
先确认 App 在运行（活动监视器里搜 `RestReminder`）。菜单栏图标太多或者屏幕太窄时，macOS 会把靠右的图标隐藏起来 —— 试试退出几个占位的菜单栏应用，或者把屏幕调宽/关掉「台前调度」后再看。

**Q3：到了时间没有声音/没有通知？**
- 声音：确认菜单里「提示音」是勾选状态；同时检查系统「系统设置 → 声音」是否静音。
- 通知：第一次启动时如果点了「不允许」，去「系统设置 → 通知 → RestReminder」里打开允许。

**Q4：我正在开会 / 演示 / 录屏，遮盖弹出来了怎么办？**
按 `空格` 最小化（或者按 `ESC` 直接跳过这次休息）；如果接下来一段时间都不希望被打扰，菜单里点「暂停计时」。
另外可以把「遮盖所有屏幕」取消勾选，只盖主屏，副屏（比如放 PPT 的那块）就不会被遮住。

**Q5：能把间隔改成菜单里没有的数值吗（比如 40 分钟）？**
菜单只提供常用档位。想自定义：① 用命令行参数临时跑（见上一节）；② 或者改源码里的默认值后重新 `./build.sh`（见下一节）。

**Q6：双屏的时候只盖了一块屏？**
检查菜单里「遮盖所有屏幕」是否被取消了；另外在「显示器 → 排列」里确认两块屏都处于活动状态。程序是启动休息时才枚举屏幕的，中途插拔显示器后重新触发的休息会按新的屏幕数量覆盖。

**Q7：休息期间不让显示器休眠，会不会很耗电？**
只在休息的那 5 分钟里短时禁止休眠，休息一结束立即释放，正常使用下影响可以忽略。笔记本电量极低时如果想让它正常黑屏，直接按 `ESC` 结束这次休息即可。

**Q8：它会不会联网、上传我的数据？**
不会。它是纯本地应用，没有任何网络代码，没有第三方依赖，不申请任何系统权限（不需要辅助功能、不需要屏幕录制）。你可以在断网状态下正常使用。

**Q9：关掉 App 再打开，计时会接着上次吗？**
不会，重新打开从完整的工作时长开始（设置项本身会保留，只有「这一轮走到哪了」不保留）。

**Q10：和 macOS 自带的「屏幕使用时间 / 提醒事项」有什么区别？**
自带功能是统计和清单，不会强制打断你。这个工具的目的就是**打断**：到点用全屏遮盖把你的工作界面盖住，让你真的起身。

## 九、卸载与清理残留

1. 菜单栏 ☕️ → 取消勾选「**开机自动启动**」（或手动删除文件，见下）。
2. 退出程序（菜单 → 退出休息提醒，或 `⌘Q`）。
3. 把 `应用程序` 里的 `RestReminder.app` 拖到废纸篓（或 `rm -rf /Applications/RestReminder.app`）。
4. 如果上面第 1 步忘了做，手动清理残留：

```bash
# 开机自启项
rm -f ~/Library/LaunchAgents/com.restreminder.app.plist
launchctl bootout gui/$(id -u)/com.restreminder.app 2>/dev/null

# 设置
defaults delete com.restreminder.app 2>/dev/null

# 单实例锁（可留，无害）
rm -f "$TMPDIR/rest-reminder.lock"
```

## 十、自己改默认值（开发者）

默认值写在 `Sources/main.swift` 的 `Settings.registerDefaults()` 里：

```swift
UserDefaults.standard.register(defaults: [
    K.work: 60.0,        // 工作时长（分钟）
    K.rest: 5.0,         // 休息时长（分钟）
    K.allScreens: true,  // 遮盖所有屏幕
    K.sound: true,       // 提示音
    K.voice: false,      // 语音叮嘱
    K.autoStart: false,  // 开机自启
])
```

改完重新构建即可：

```bash
./build.sh run
```

注意：已经被保存过的设置在偏好文件里，默认值改动不会覆盖它 —— 想看到新默认值，先 `defaults delete com.restreminder.app`。

想改界面文案：所有中英文案集中在 `L` 枚举里（`L.s("中文", "English")`），改一处两种语言都在。

## 十一、隐私说明 / 已知限制 / 反馈

**隐私**：无网络请求、无遥测、无第三方 SDK；所有设置只存在你本机的偏好文件里。

**已知限制**

- 未做 Apple 公证，首次打开需要手动放行（见上）。
- 菜单里的间隔档位是固定的 8 档 / 4 档；要别的数值需改代码或用命令行参数。
- 不保留「计时进度」，退出重开从整轮开始。
- 只支持 macOS 14+；不支持 Windows / Linux。

**反馈**：欢迎在 [Issues](https://github.com/huacracker/RestReminder/issues) 里报问题或提建议。
