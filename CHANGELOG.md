# Changelog

## 1.0.0 — 2026-10-17

First release.

- Menu bar timer: 60 min work → 5 min break by default, both adjustable from the menu (work 15–120 min, break 3–15 min)
- Full-screen break overlay on every display, with a countdown ring and a "minimize" pill that keeps counting down in the corner
- Finish early with the button / `ESC` / `Return`; minimize with `Space`
- Display sleep blocked during breaks; sound, optional `say` voice reminder, notification
- Launch at login via its own LaunchAgent
- UI in Chinese or English depending on the system language
- Self-test, fast-cycle and PNG snapshot command line flags for testing without waiting an hour
